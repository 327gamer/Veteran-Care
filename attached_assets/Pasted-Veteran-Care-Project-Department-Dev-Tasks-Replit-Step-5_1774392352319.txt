Step 57.23 – Make Verified Partners Inside Regular Resources Open Internal Detail View

IMPORTANT:
Please treat this as ONE focused task only.
Do not make any other changes in this step.
Fix only how verified partners behave when shown inside regular Resources category results.

==================================================
ISSUE – VERIFIED PARTNERS INSIDE REGULAR RESOURCES STILL CLICK OUTBOUND
==================================================

CURRENT PROBLEM:
Inside regular Resources category results, verified partners are correctly appearing at the top and visually stand out with the highlighted verified-partner treatment.

Examples:
- BootPrint
- Tri-County Veterans Support Network

That part is good.

However, when the user clicks one of these verified partners from inside regular Resources, it still takes them straight to the external website instead of opening an internal detail view.

This is inconsistent with:
- regular resources
- trusted services provider detail flow
- the desired platform behavior

Also:
- these verified partner cards inside regular Resources do not currently expose the same internal save/favorite/detail experience we want

==================================================
REQUIRED FIX
==================================================

Inside REGULAR RESOURCES category results:

1. Verified partner cards should NOT use outbound website as the primary click behavior
2. Primary click on a verified partner should open an INTERNAL detail view/page
3. That internal detail should behave like a first-class platform entity, similar to:
   - regular resource detail flow
   - trusted services provider detail flow

The internal detail view should include, where available:
- overview
- contact information
- website link
- phone number
- location
- connect/request action if applicable
- favorite/save action

External website should remain available as an action INSIDE the detail view, not as the primary click.

==================================================
FAVORITE / SAVE REQUIREMENT

Verified partners shown inside regular Resources should also support the platform’s normal save/favorite pattern.

REQUIRED:
1. visible heart/save action on listing and/or detail
2. user can save verified partner
3. saved item should follow the same saved/favorites pattern used elsewhere in the app
