1) Replit Prompt Version (SHORT) — Copy/Paste

Build VeteranCare.com as a mobile-first app with a location-first experience. On first launch, require the user to either (A) enable GPS location or (B) manually select State → City/Town (dropdowns), with optional zip. Save locationMode, state, city, zip, and lat/lng (if GPS). The bottom tab “Near Me” must display the existing category tiles (Benefits & VA Claims, Healthcare, Crisis Help, Mental Health, Housing Support, Employment, Education & GI Bill, Legal & Financial, Family & Caregivers, Military Records, Transition). When a user taps Near Me, show the category tiles filtered to their location; tapping a category lists resources for that category filtered by city/state or GPS radius.

Implement in stages to control cost:
Stage 1: location setup + Near Me filtering (no scraping).
Stage 2: seed a South Carolina-only resource database (starter set).
Stage 3: add Favorites + “My Resources” tab with folders and pinned items.
Stage 4: add controlled ingestion for South Carolina from approved government domains only using a Source Registry + hard crawl limits; ingestion outputs drafts requiring admin approval.
Stage 5: expand state-by-state nationwide via queued ingestion jobs (never one nationwide run).

AI Guide must use the same resource database (RAG-style retrieval) and default to SC-local results when the user location is in South Carolina.

2) South Carolina Starter Seed List (MVP) — Structured + Easy to Import

How to use this seed list
	•	Create a Resources table/collection with these minimum fields:
title, category, descriptionPlainEnglish, stepsChecklist[], websiteUrl, sourceName, sourceUrl, state, city, status
	•	For now set: state = "SC" and city = "Statewide" for statewide items.
	•	Later you can duplicate records per city (Charleston, Columbia, Greenville, etc.) as you ingest or curate.

Tip: This seed list is intentionally “safe” on details (no phone/address) and points to official directories you can trust and expand later.
