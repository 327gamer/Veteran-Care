==================================================
QUALITY RULES
==================================================

Only add resources with enough reliable information to be useful.

Each row should include whenever available:

- organization name
- category
- city
- county
- state
- phone
- website
- address
- short description
- veteran relevance
- source URL

Prefer official or highly credible sources.

==================================================
SKIP IMMEDIATELY IF:
==================================================

- no clear service purpose
- no reliable source
- outdated or suspicious information
- duplicate data already in system
- unclear location
- broken source
- verification friction
- progress stalls
- low-value one-off source consuming time

Skip and continue.
