### ENFORCE GLOBAL UI RULES + FIX PROFILE & PARTNER DASHBOARD

Before addressing the issues below, we need to reinforce a platform-wide rule:

-------------------------------------
GLOBAL UI / UX RULE (NON-NEGOTIABLE)
-------------------------------------

Every screen, modal, and component MUST:

- be mobile-first (primary device)
- fully fit within viewport width
- have NO horizontal overflow
- have NO left/right scrolling
- support clean vertical scrolling only
- ensure all buttons and inputs are accessible
- behave correctly on iPhone Safari (primary test case)

This rule is NOT optional and must be applied to ALL existing and future components.

We are seeing repeated violations of this standard, which means fixes are being done in isolation instead of following system-level rules.

-------------------------------------
ISSUE 1 — MY PROFILE IS NOT MOBILE-CLEAN
-------------------------------------

The personal “My Profile” view is still breaking the global UI rule.

Problems:
- horizontal overflow exists
- user can drag left/right
- layout exceeds viewport width
- inconsistent mobile behavior vs other pages

This directly violates the platform UI standard.

REQUIRED FIX:
- enforce container max-width and overflow-x: hidden
- ensure all fields/components scale within viewport
- eliminate any element causing width expansion
- confirm behavior on iPhone (Safari)

This must be treated as a system-level layout correction, not a patch.

-------------------------------------
ISSUE 2 — PARTNER DASHBOARD IS MISSING BUSINESS PROFILE

The Partner Dashboard currently shows:

This creates confusion and an incomplete experience.
