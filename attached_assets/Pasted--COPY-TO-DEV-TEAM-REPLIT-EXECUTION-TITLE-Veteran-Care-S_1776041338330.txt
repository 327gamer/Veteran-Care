-------------------------------------
OBJECTIVE
-------------------------------------

Provide dynamic guidance for batch execution so admin can safely decide:

- how many leads to include in the next batch
- whether to increase or reduce batch size
- whether performance is improving or declining

-------------------------------------
REQUIREMENT 1 — RECOMMENDED BATCH SIZE
-------------------------------------

Add derived field:

- recommended_batch_size

Based on avg_success_rate from last 3–5 batches:

IF avg_success_rate ≥ 90%:
→ recommended_batch_size = "4–5"

IF avg_success_rate 80–89%:
→ recommended_batch_size = "3–4"

IF avg_success_rate < 80%:
→ recommended_batch_size = "1–2"

-------------------------------------
REQUIREMENT 2 — TREND ANALYSIS
-------------------------------------

Use last 3–5 batches:

Compare success_rate trend:

IF increasing:
→ trend_direction = "improving"

IF roughly equal:
→ trend_direction = "stable"

IF decreasing:
→ trend_direction = "declining"

Keep logic simple:
- compare last batch vs average of prior batches

-------------------------------------
REQUIREMENT 3 — GUIDANCE TEXT
-------------------------------------

Return guidance text:

SAFE (≥90%):
"Batch performance is strong. You can cautiously increase batch size."

STABLE (80–89%):
"Batch performance is stable. Maintain current batch size."

CAUTION (<80%):
"Batch performance is declining. Reduce batch size and review failures."

-------------------------------------
REQUIREMENT 4 — EXTEND EXISTING ENDPOINT
-------------------------------------

Extend:

GET /api/admin/batch-performance-summary

Add:

- recommended_batch_size
- trend_direction
- guidance_text

Do NOT create new endpoints unless necessary.

-------------------------------------
REQUIREMENT 5 — ADMIN VISIBILITY
-------------------------------------

Update “Batch Performance” panel to include:

- recommended batch size (large visible text)
- safety level badge (SAFE / STABLE / CAUTION)
- trend direction (↑ improving / → stable / ↓ declining)
- guidance message

-------------------------------------
