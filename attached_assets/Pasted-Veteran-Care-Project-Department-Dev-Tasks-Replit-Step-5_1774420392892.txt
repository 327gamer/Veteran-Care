- email
- phone (optional)
- region_type (optional)

- referral_code (optional if already supported)
- status
- notes (optional)

But do NOT expand beyond Phase 1.

==================================================
2) AMBASSADOR LIST VIEW
==================================================

Build a clean list/table view for all ambassadors.

Display at minimum:
- display_name
- code
- email
- region_type
- region_value
- status
- total links
- total clicks
- last activity

Requirements:
- each row clickable
- clicking opens Ambassador Detail View
- designed for non-technical admin usability
- should support future filters, but only basic view is required now

Data source:
- ambassadors = identity/profile
- ambassador_links = link counts / click counts / last activity aggregation

==================================================
3) BASIC AMBASSADOR DETAIL VIEW
==================================================

Create a basic ambassador detail screen/view that shows:

A. Profile summary
- display_name
- code
- email
- phone
- region
- status
- notes if present

B. Owned links summary
For each link show at minimum:
- link_name
- short_url or full_url
- click_count
- first_clicked_at
- last_clicked_at
- active/inactive if available

C. Basic activity summary
At minimum:
- total links
- total clicks
- first activity
- last activity
