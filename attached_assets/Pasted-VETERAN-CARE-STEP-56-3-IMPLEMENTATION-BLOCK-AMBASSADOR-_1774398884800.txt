========================================
PART 1 — AMBASSADOR LINK MODEL
========================================

Create a structured ambassador link system using the already-existing Veteran Care entry URLs:

- /start
- /get-help
- /resource-center
- /partners

The system must support unique links by:

1. ambassador
2. audience
3. channel
4. campaign

Required UTM logic:

- utm_source = platform/channel
  Examples:
  facebook
  instagram
  email
  linkedin
  text
  qr
  flyer

- utm_medium = ambassador
  Value should be:
  ambassador

- utm_campaign = campaign name
  Examples:
  sc_launch
  sc_veteran_help
  sc_case_manager_drive
  sc_partner_growth

- utm_content = ambassador identifier
  Examples:
  john_smith
  sarah_jones
  mike_brown

Optional:
- utm_id = unique internal tracking ID if useful for future automation
