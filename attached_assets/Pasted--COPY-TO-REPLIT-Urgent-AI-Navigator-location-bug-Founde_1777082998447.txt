Urgent AI Navigator location bug.

Founder live test shows the AI Navigator is still not following the correct location priority logic.

Observed issues:

1. Founder has location enabled, asked:
“Can you please give me resources for food and housing?”
The AI returned North Carolina resources instead of using current enabled location.

2. Founder then explicitly asked:
“Please give me resources for housing and food in South Carolina.”
The AI still returned North Carolina information.

This is incorrect and must be fixed before further national rollout.

==================================================
REQUIRED AI NAVIGATOR LOCATION PRIORITY
==================================================

The AI Navigator must use this order every time:

1. Explicit user-requested location FIRST
If the user says:
- in South Carolina
- in Georgia
- in Florida
- in Charlotte
- in Atlanta
- for a friend in another state
- near Tampa
- housing in SC
- food in Charleston

That explicit location must override everything else, including browser location.

Reason:
A user may be physically in South Carolina but asking for help for a friend in North Carolina, Georgia, Florida, etc.

2. Browser/app location SECOND
If the user does not mention a location, but location is enabled, use the user’s detected location.

Example:
User says:
“I need food and housing help.”

If current location is Charleston / SC, return Charleston / South Carolina resources.

3. Ask location THIRD
If no explicit location is mentioned and no browser/app location is available, ask:

“What city and state should I search in?”

Do not return random state resources.

4. Crisis exception
If user is suicidal or in immediate danger:
Show 988 / emergency resources first, then ask for location for local crisis resources.

BUGS TO INVESTIGATE

Please investigate why:

- enabled browser location did not drive results
