==================================================
ISSUE – TRUSTED SERVICES / VERIFIED PARTNERS DO NOT FOLLOW PLATFORM DETAIL FLOW
==================================================

CURRENT PROBLEM:
Trusted Services partners and verified partners do not currently behave like first-class platform entities.

Examples:
- In Trusted Services, when a user clicks a category like Housing and sees providers such as Blueprint and Tri-County Veteran Support Network, users can often connect or go directly to the provider website.
- In regular Resources, entities generally behave more like in-platform items with detail views and save/favorite patterns.

WHAT IS MISSING:
1. No visible heart / favorite save action near some partner listings
2. Clicking a partner can send users straight to the external website instead of opening an internal platform detail page
3. The flow is inconsistent with regular resources
4. This weakens UX, tracking, and partner subscription value

==================================================
REQUIRED FIX
==================================================

Trusted Services / verified partners should behave more like regular platform resources.

REQUIRED BEHAVIOR:
1. Add a visible heart / favorite action for Trusted Services / verified partner listings
2. Do NOT make external website the primary first-click behavior
3. Primary click on a partner should open an internal detail view/page
4. That partner detail view should include, where available:
   - overview
   - contact information
   - website link
   - phone number
   - connect / request action if applicable
   - favorite / save action
5. External website should remain available as an action INSIDE the detail view, not the primary first click
6. Keep tracking intact so partner interaction and downstream monetization can be measured

==================================================
GOAL
==================================================

Trusted Services / verified partners should feel like first-class platform entities, not outbound links.
