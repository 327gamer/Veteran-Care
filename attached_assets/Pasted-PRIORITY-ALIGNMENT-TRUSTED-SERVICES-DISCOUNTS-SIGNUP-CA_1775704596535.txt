-------------------------------------
1. CRITICAL SYSTEM RULE (NON-NEGOTIABLE)
-------------------------------------

Trusted Services and Veteran Discount Services & Products are the SAME system.

This includes:
- Trusted Services (top nav)
- Veteran Discount Services & Products (homepage card)
- /discounts page
- Trusted Partner signup flow

They must:
- use the same category structure
- use the same subcategory structure
- use the same data mapping
- operate as one ecosystem

Reason for naming difference:
- the full name was too long for mobile UI
- “Trusted Services” is just a shortened label

But technically and architecturally:
ALL are the same system.

-------------------------------------
2. ECOSYSTEM RULE (DO NOT BREAK)
-------------------------------------

This platform is fully interconnected via:

- UTM tracking
- ambassador attribution
- referral tracking (on-platform and off-platform)
- Stripe subscriptions
- partner records
- lead routing

Because of this:

DO NOT break:
- category relationships
- partner mappings
- attribution chains
- Stripe-linked data
- routing logic

-------------------------------------
3. CORE BUSINESS MODEL (MUST BE PRESERVED)
-------------------------------------

A) Resources = full directory
- ~500+ listings
- location-based
- includes ALL organizations
- includes trusted partners (elevated / verified)

B) Trusted Services / Discounts = premium layer
- only paying / trusted partners
- monetized environment

C) One-way relationship:
- trusted partner signs up →
  appears in Trusted Services / Discounts
  AND appears elevated in Resources

- regular resources DO NOT appear in Trusted Services

This must remain intact.
