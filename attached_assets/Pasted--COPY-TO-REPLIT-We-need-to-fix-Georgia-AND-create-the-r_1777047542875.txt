We need to fix Georgia AND create the reusable national state-rollout system before moving further.

Current issue:
Georgia is not behaving like SC/NC, and Georgia has far too few resources for a state of its size. Atlanta, Savannah, Augusta, Macon, Columbus, Athens, and the surrounding metros should have hundreds to thousands of usable resources across categories.

This needs to be treated as both:

1. Georgia repair
2. National rollout engine design

Do not treat this as a one-off patch.

--------------------------------------------------
PART 1 — GEORGIA CITY DROPDOWN MUST MATCH SC/NC
--------------------------------------------------

Georgia city dropdown behavior must match the locked SC/NC behavior.

Required rule:

ALL Georgia cities/towns/metros loaded for the state must appear in the city dropdown regardless of whether that exact city has rows in the selected category/subcategory.

Do NOT category-limit the city dropdown.

Example:
If user selects:

State = Georgia
Category = Housing
City dropdown should still show the full Georgia city list, not only Atlanta, Sandy Springs, and Savannah.

If user selects:

State = Georgia
Category = Food
City dropdown should still show the full Georgia city list, not only the cities with food rows.

Same rule must apply across:

- Near You page
- Resources page
- Category pages
- Subcategory pages
- Chip-filtered pages
- State mode
- City mode

The dropdown should be a location selector, not a “cities with exact category rows only” selector.

--------------------------------------------------
PART 2 — GEORGIA FILTERING / FALLBACK RULES
--------------------------------------------------

When user selects Georgia:

Only Georgia resources plus national fallback should show.

Never show SC or NC resources under Georgia filters.

When user selects:

Georgia + Atlanta

Results should be:

1. Atlanta exact resources first
2. Nearby Georgia metro resources second
3. Statewide Georgia resources third
4. National fallback last

When user selects:

Georgia + small city with no direct rows

Results should NOT be empty.

Results should show:

1. Nearest Georgia city/metro resources if coordinates exist
2. Statewide Georgia resources
3. National fallback

Same fallback logic should apply for every future state.

Manual state/city choice must override the user’s phone location.

If user is physically in South Carolina but manually selects Georgia + Atlanta, the system must show Georgia/Atlanta results, not “near me” South Carolina results.

--------------------------------------------------
PART 3 — VERIFIED PARTNER RULES
--------------------------------------------------

Verified Partners must respect state logic.

If State = Georgia:
Show only:
- Georgia verified partners
- National verified partners

Do NOT show:
- SC-only partners
- NC-only partners

If State = South Carolina:
Show:
- SC verified partners
- National verified partners

If State = North Carolina:
Show:
- NC verified partners
- National verified partners

If no state filter / All mode:
Current broader behavior can remain.

If Near Me mode:
Show partners based on location/distance logic only.

Partner rules must be handled separately from public resource rows.

No state bleed.
