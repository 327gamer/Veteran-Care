Add a second type of ambassador tracking link:

→ “General / Homepage Link”

This allows ambassadors to send traffic to the homepage while preserving full UTM attribution across the entire user journey.

1. HOMEPAGE UTM LINK GENERATION

For every ambassador + campaign:

Generate an additional tracking URL:

BASE:
https://veterancare.com/

OR:

- utm_source = ambassador_code (e.g. colin_slaven)
- utm_medium = ambassador
- utm_campaign = campaign_name (e.g. launch)
- utm_content = homepage

IMPORTANT:
utm_content must clearly distinguish link type.

Examples:
- homepage
- landing_housing
- landing_jobs

https://veterancare.com/?utm_source=colin_slaven&utm_medium=ambassador&utm_campaign=launch&utm_content=homepage
