OBJECTIVE
-------------------------------------

Guide admin toward the most effective follow-up actions using real conversion performance data.

-------------------------------------
REQUIREMENT 1 — BEST / WORST ACTION IDENTIFICATION
-------------------------------------

Use existing recovery performance data to determine:

- best_performing_follow_up_type
- lowest_performing_follow_up_type

Use:
- total_sent
- total_recovered
- conversion_rate

-------------------------------------
REQUIREMENT 2 — RECOMMENDED ACTION BANNER
-------------------------------------

Inside Activation Funnel panel:

Add:

→ “Recommended Action” banner

Examples:

- “Urgency follow-ups are converting best — consider using this first”
- “Reminder emails are underperforming — use cautiously”

Display only when sufficient data exists.

-------------------------------------
REQUIREMENT 3 — CONTEXTUAL PARTNER SUGGESTIONS
-------------------------------------

For each stalled partner row:

Add “Suggested Action”:

IF invited >48h:
→ suggest: urgency

IF invited 24–48h:
→ suggest: reminder

IF subscribed but not active:
→ suggest: payment_recovery

-------------------------------------

STRICT:

- no automation
- simple deterministic logic only

-------------------------------------

-------------------------------------

Enhance Activation Funnel panel:

- top banner → recommended action

-------------------------------------
REQUIREMENT 6 — NO SYSTEM IMPACT
-------------------------------------

Do NOT modify:

- routing
- billing
- Stripe
- follow-up sending logic
