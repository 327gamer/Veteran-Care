==================================================

QUALITY RULES
==================================================

Only add resources with enough reliable information to be useful.

Each row should include whenever reasonably available:

- organization name
- category
- city
- county
- state
- phone
- website
- address
- short description
- veteran relevance
- source URL

Prefer:

1. official sources
2. government sources
3. known nonprofit sources
4. hospital systems
5. credible directories
