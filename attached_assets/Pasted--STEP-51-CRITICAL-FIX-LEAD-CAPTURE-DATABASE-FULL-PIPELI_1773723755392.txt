🧩 STEP 1 — CREATE LEADS TABLE

Create the following table in PostgreSQL:

CREATE TABLE trusted_service_leads (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  provider_id UUID,
  provider_name TEXT,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT,
  city TEXT,
  state TEXT,
  message TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
